# AHC Data: Fe (111)

This directory contains compact processed data for the bcc Fe `(111)`
magnetization-rotation figures:

- `fit_ahc_para.pdf`
- `fit_ahc_perp.pdf`
- `fit_ahc_axis.pdf`

The CSV files were extracted from the old read-only repository:

```text
tests/Fe/FM_sqa_111/angle_dep_ahc_dft.xml
tests/Fe/FM_sqa_111/angle_dep_ed.xml
```

No raw DFT, Wannier, HDF5, or WannierBerri working files are stored here.
