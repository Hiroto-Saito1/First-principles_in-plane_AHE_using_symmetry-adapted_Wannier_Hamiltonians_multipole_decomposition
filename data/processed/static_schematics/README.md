# Static Manuscript Schematics

The schematic manuscript figures listed in this inventory group are not
tracked as figure PDFs because they are not generated by repository scripts.
They include:

- AHC-vector and rotation-plane definitions.
- bcc Fe structure panels.
- QtDraw multipole schematics.
- strained-structure schematics.

These figures are static publication artifacts rather than numerical
processed data. They are classified as `not_included` in
`data/processed/figure_inventory.csv`.
