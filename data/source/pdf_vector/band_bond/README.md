# Band/Bond Vector Recovery Sources

This directory contains the per-cutoff band-structure PDFs used to recover the
compact `band_bond` processed CSV:

- `band_1.pdf`
- `band_2.pdf`
- `band_3.pdf`
- `band_4.pdf`
- `band_5.pdf`
- `band_10.pdf`
- `band_20.pdf`
- `band_35.pdf`

These files are source snapshots from the local manuscript workspace. The
original compact band-path CSV exports were not preserved, so the repository
rebuild path falls back to the vector curves embedded in these Matplotlib PDFs.

Recovery command:

```bash
python scripts/workflow/extract_pdf_vector_data.py --target band-bond
```

The manuscript composite `band_bond.pdf` is now regenerated by
`scripts/reproduce_figures/plot_band_bond.py`. The committed PDFs here remain
source provenance, not the final paper-figure artifact.
