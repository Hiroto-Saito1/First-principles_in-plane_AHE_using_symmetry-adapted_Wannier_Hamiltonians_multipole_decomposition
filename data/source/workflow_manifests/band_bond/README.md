# `band_bond` Reference-Information Contract

This directory records the minimum information content required for the
paper-facing `band_bond.pdf` panel.

The contract does not try to reproduce the final manuscript PDF byte-for-byte.
Instead, it fixes the paper-facing role of the recovered compact curve CSV:

- the composite includes the committed cutoff set
  `1, 2, 3, 4, 5, 10, 35`;
- each included cutoff keeps both `DFT` and `model` series;
- the recovered DFT series retains its 16 band curves for every cutoff; and
- the recovered model series retains the per-cutoff reconstructed curve count
  seen in the tracked vector recovery.

The tracked compact CSV still contains cutoff `20` because it was recovered
from the archived per-cutoff vector PDFs, but that cutoff is intentionally not
part of the paper-facing composite generated by `plot_band_bond.py`.
