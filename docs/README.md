# Documentation Guide

This directory holds the detailed reference documents for the public
reproducibility package.

## Start Here

- `../README.md`: project overview and quick start.
- `../CHANGELOG.md`: release notes, including the `v0.1.0` baseline.
- `../plan.md`: completion notes and optional future upgrades.

## Repository Maps

- `paper_mapping.md`: maps manuscript figures to processed data and plotting
  scripts.
- `data_inventory.md`: records what compact data are committed and which large
  artifacts are regenerated by recipe.
- `source_inventory.md`: tracks manuscript-facing source provenance and the
  repository destination of each item.

## Workflow Notes

- `workflow.md`: end-to-end computational workflow, from first-principles
  inputs through decomposition and figure reproduction.
- `../scripts/workflow/generate_large_files.md`: recipe notes for large
  intermediates intentionally omitted from Git.
- `qe_patch/README.md`: notes for the archived `pw2wannier90` patch.

## Recommended Reading Order

For a first pass through the repository:

1. read `../README.md`;
2. inspect `paper_mapping.md` and `data_inventory.md`;
3. use `workflow.md` when you want to understand where a processed dataset or
   omitted large artifact came from;
4. consult `../plan.md` for the final scope decision and remaining optional
   upgrades.
