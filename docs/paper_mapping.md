# Manuscript Mapping

This file maps manuscript artifacts to repository data and scripts. It is a
living document and should be updated whenever processed data or figure
scripts are added.

Manuscript preprint: [arXiv:2601.05689](https://arxiv.org/abs/2601.05689).

## Current Status

The repository tracks reference PDFs only for plots that can be generated by
repository scripts. Repository-local reproduction scripts generate equivalent
data figures under `results/figures/`. Static manuscript schematics,
QtDraw-style multipole drawings, and structure panels are recorded in the
inventory but are not tracked as figure PDFs. Compact source snapshots,
CSV/JSON data, and plotting scripts have been added for the band/bond, primary
AHC, rank-resolved, strain, multipole-coefficient, and minimal-model figures.
The complete machine-readable inventory is:

```text
data/processed/figure_inventory.csv
```
