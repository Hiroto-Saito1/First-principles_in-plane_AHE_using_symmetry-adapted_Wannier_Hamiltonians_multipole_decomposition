# Archived Code Redistribution Status

This repository includes copied archived workflow module trees under:

- `src/symwan_multipie/symwannier/`
- `src/symwan_multipie/wannier_utils/`

These paths are present because they are needed to preserve the manuscript-era
workflow surface in the public reproduction package. Their upstream
redistribution status has not yet been confirmed.

Until that clarification is obtained:

- those copied archived trees are excluded from the repository's local MIT
  grant;
- the rest of the repository follows the mixed-license policy described in
  `LICENSE`; and
- downstream reuse should rely on `LICENSE` as the authoritative statement of
  scope.

This status note is intentionally narrower than a license file. It exists so
reader-facing documentation and tests keep the current exclusion visible until
the original redistribution basis is confirmed or the archived code is removed
from the public tree.
