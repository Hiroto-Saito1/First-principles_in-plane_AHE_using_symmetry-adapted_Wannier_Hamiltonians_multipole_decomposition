# Paper Figures

This directory contains reference PDF files for the plots in
[Phys. Rev. B 114, 084410 (2026)](https://doi.org/10.1103/wbhp-rvb7) that can
be generated by repository scripts. A corresponding preprint is available at
[arXiv:2601.05689](https://arxiv.org/abs/2601.05689).

Static manuscript-only schematics, QtDraw-style multipole drawings, structure
panels, and any future manuscript composites without a repository plotting
path are not tracked here. They remain listed in
`data/processed/figure_inventory.csv` as `not_included` or
`workflow_required`.

Processed data, source snapshots, and reproduction scripts are tracked under
`data/source/`, `data/processed/`, and `scripts/reproduce_figures/`.

The source-to-script mapping is recorded in
`data/processed/figure_inventory.csv` and `docs/paper_mapping.md`.
