# Quantum ESPRESSO DFT Input Scope

This directory contains the public DFT input layer for the Fe workflows used by
the manuscript. The unstrained bcc Fe SCF/NSCF inputs are the common upstream
branch for the `(111)` and `(103)` magnetization-rotation calculations. The
`[103]` strain workflow starts from the same physical settings but uses
volume-preserving strained cells generated by
`scripts/workflow/strain_103_cell.py`.

Expected pseudopotential destinations:

```text
pseudopotentials/Fe.pbe-spn-rrkjus_psl.0.2.1.UPF
pseudopotentials/Fe.rel-pbe-spn-rrkjus_psl.0.2.1.UPF
```

The pseudopotentials are not committed until redistribution permission is
confirmed. The public templates mirror the source workflow in which the
collinear SCF step uses the scalar-relativistic Fe pseudopotential and the
noncollinear SOC NSCF step uses the fully relativistic Fe pseudopotential.
Record the source URL and checksum for both files before running a production
calculation.

Workflow order:

1. Run `fe_bcc_unstrained/scf.in` and `fe_bcc_unstrained/nscf.in` for the
   base Fe calculation.
2. Use the resulting NSCF wavefunctions with the Wannier inputs under
   `inputs/wannier/fe_bcc_unstrained/`.
3. For `[103]` strain, generate each strained cell, update the structure block
   in `fe_bcc_strain_103/scf.in`, and then rerun the same DFT-to-Wannier
   workflow.

Generated `outdir` contents, wavefunctions, charge densities, cluster logs,
and scratch directories are not committed. If any generated file exceeds
100 MB, keep it outside Git and document its downstream use in
`scripts/workflow/generate_large_files.md`.
