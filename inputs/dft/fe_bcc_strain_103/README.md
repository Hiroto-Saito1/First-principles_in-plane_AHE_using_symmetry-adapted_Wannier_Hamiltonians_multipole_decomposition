# bcc Fe `[103]` Strain DFT Inputs

This directory contains the initial structure input template for the
volume-preserving `[103]` strain workflow. The strain-cell generation logic is
implemented in `scripts/workflow/strain_103_cell.py`; generated strained
working directories are not committed.

Expected pseudopotential:

```text
pseudopotentials/Fe.pbe-spn-rrkjus_psl.0.2.1.UPF
```

The pseudopotential itself is not committed until redistribution permissions
are confirmed.
